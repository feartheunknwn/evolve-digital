# 🚀 MarketAI: AI Automation for Digital Marketing

**Automate your social media, lead gen, and customer engagement with AI — 24/7, no code required.**

MarketAI is an open-source toolkit that helps marketers, agencies, and founders use chatbots + AI agents to get consistent customers on autopilot. Think of it as your free alternative to expensive SaaS marketing tools.

### ✨ What It Does

- **AI Chatbots**: Deploy website/WhatsApp/IG chatbots trained on your business data. Handles FAQs, qualifies leads, books calls
- **Auto-DM Agents**: Instagram & Facebook comment-to-DM flows that capture leads while you sleep
- **Content Automation**: Schedule posts, repurpose content, and auto-reply to comments with AI
- **Lead-Gen Flows**: n8n templates that connect forms → CRM → email sequences → Slack alerts
- **Analytics Dashboard**: Track conversations, conversions, and ROI from all AI touchpoints

### 🛠️ Tech Stack

- **Frontend**: Next.js 14 + Tailwind CSS + Shadcn/ui
- **AI Layer**: LangChain.js, OpenAI / Gemini API, Supabase VectorStore for memory
- **Automation**: n8n workflows + ManyChat templates 
- **Database**: Supabase (Postgres) + Redis for caching
- **Deploy**: Vercel (frontend) + Railway/Self-host (n8n)
